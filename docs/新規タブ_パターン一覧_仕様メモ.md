# 新規タブ「パターン一覧」仕様・利用ガイド

## 1. 概要・目的

パターン一覧タブは、**登録した文字列パターンを一括でカーニング結果とともに確認・補正する**ためのタブです。

- **パターン**は `pattern_list.json` で管理し、50音・濁音・半濁音などをローマ字（ヘボン式・訓令式）でグループ単位に登録する。
- 選択した**フォント**について、`kerning_categories.json` の `font_overrides` から補正値を読み込み、初期表示および描画に反映する。
- パターンごとのカーニング後キャンバスと、**全ペアを一覧にした文字間マニュアル調整**で補正値を編集し、**kerning_categories.json 全体のエクスポート**で保存できる。

基本設定タブの設定（カーニングモード・フォントなど）とは**独立**しており、タブを切り替えても互いに影響しません。

---

## 2. パターン一覧タブの使い方（詳細）

### 2.1 タブを開く

1. 画面上部のタブで **「パターン一覧」** をクリックする。
2. 初回表示時、`pattern_list.json` が自動で読み込まれる。
3. 基本設定タブ用の「キャンバスエリア」「文字間マニュアル調整」は非表示になり、パターン一覧タブ用の設定・キャンバス一覧・マニュアル調整だけが表示される。

### 2.2 設定項目（タブ内で共通）

いずれも**このタブ専用**の値です。変更すると**このタブ内の全キャンバス**に反映されます。

| 項目 | 説明 |
|------|------|
| **カーニングモード** | Phase0（ルールベース） / Phase1（学習値）。比較モードはなし。 |
| **フォント** | ドロップダウンで選択。基本設定タブのフォント一覧と同期。 |
| **カスタムフォント名** | 直接入力する場合に使用。入力があるとフォントのドロップダウンより優先。 |
| **スタイル** | デフォルト / 和モダン / 北欧 / モダン / カジュアル。 |
| **フォントサイズ (px)** | 20〜200。全キャンバスで共通。 |
| **カーニング前の文字間（px）** | スライダーで指定。カーニング計算の基準になる。 |
| **Phase0幅アンカー** | チェックで、カーニング後の幅をカーニング前の幅に合わせる。 |

### 2.3 キャンバス一覧の見方

- **グループ名**（例: 母音、50音（ヘボン式））が見出しで表示され、その下にそのグループのパターンが並ぶ。
- **表示は 3 列**。各項目は「文字列ラベル ＋ カーニング後キャンバス」。
- キャンバスサイズは **幅 520px × 高さ 80px**。左余白は 8px で、長い文字列のはみ出しを抑えている。
- フォントを選択していない場合は「フォントを選択してください」と表示される。

### 2.4 文字間マニュアル調整（一覧）

- **対象**: 現在選択しているフォント。全パターンで出現する**全ペア**を 1 つのテーブルにまとめて表示する。
- **列**: # / ペア / Δ(px) / リセット。
- **初期値**: `kerning_categories.json` の `font_overrides[選択フォント名].pair_adjustments` から読み込んだ値。対象フォントが `font_overrides` にない場合は空で始まる。
- **編集**:
  - Δ(px) の数値入力、**＋／－**ボタン（0.1 刻み）、**リセット**でそのペアを削除。
  - 編集内容はメモリ上（`patternTabFontOverrides`）に即反映され、キャンバスも再描画される。
- **永続化**: このタブでは LocalStorage には保存しない。**「kerning_categories.json をエクスポート」**でファイルをダウンロードし、プロジェクトの `kerning_categories.json` と差し替える運用。

## 3. pattern_list.json の仕様と編集方法

### 3.1 ファイルの場所

- **ファイル名**: `pattern_list.json`
- **配置**: `phase0-demo.html` と同じディレクトリ（プロジェクトルート）。

### 3.2 JSON の構造

```json
{
  "groups": [
    {
      "name": "グループ名（表示用見出し）",
      "items": ["文字列1", "文字列2", ...]
    }
  ]
}
```

- **groups**: グループの配列。`name` が画面の見出し、`items` がその下に並ぶパターン（文字列）の配列。
- **フラットな一覧**だけ必要な場合は、`groups` の代わりに `items` をルートに置く形式も可（その場合は「一覧」という 1 グループとして扱われる）。

### 3.3 現在の内容（デフォルト）

同じ種目は 1 グループに統合し、**小文字 → 大文字 → 先頭大文字**の順で並べている。

| グループ名 | 内容例 |
|------------|--------|
| **母音** | aiueo, AIUEO, AiUeO および母音ペア文字列（aiauaeao, AIAUAEAO, AiAuAeAo など） |
| **50音（ヘボン式）** | kakikukekok, KAKIKUKEKOK, KaKiKuKeKoK, sashisusesos, ... , n |
| **50音（訓令式）** | 同上だが si/ti/tu/hu 等の訓令式表記 |
| **濁音（ヘボン式）** | gagigugegog, GAGIGUGEGOG, GaGiGuGeGoG, zajizuzezoz, ... |
| **濁音（訓令式）** | zazizuzezoz, ZaZiZuZeZoZ, ... |
| **半濁音** | papipupepop, PAPIPUPEPOP, PaPiPuPePoP |

- パターンは**ローマ字**（ヘボン式・訓令式）。
- 子音行は「か行」なら `kakikukekok` のように**同じ子音で連結し、末尾に子音**を付けた形式。
- 母音は `aiueo` に加え、母音同士のペアを並べた文字列も含む。

### 3.4 編集の仕方

- アプリ内に「登録」ボタンはない。**pattern_list.json をテキストエディタで直接編集**する。
- 編集後、パターン一覧タブを一度他タブに切り替えてから再度「パターン一覧」を開くか、ページを再読み込みすると、新しい内容が反映される（初回のみ JSON を fetch するため、再表示で再読み込みされる）。

## 4. 文字間マニュアル調整の保存（エクスポート）

### 4.1 保存の流れ

1. パターン一覧タブでフォントを選択し、必要に応じてマニュアル調整テーブルで Δ(px) を編集する。
2. **「kerning_categories.json をエクスポート」**ボタンをクリックする。
3. 対象フォントが未選択の場合はアラートで促される。
4. 実行すると、**現在の kerning_categories.json を再取得**し、**選択フォントの `font_overrides` だけ**を、今編集している補正値で更新する。
   - 既存の `font_overrides[フォント名]` があれば **上書き**（`pair_adjustments` を差し替え、その他のキーは維持）。
   - なければ**新規作成**。
   - 他のフォントや `kerning_categories` / `pair_adjustments` などは**そのまま**出力する。
5. 更新後の **kerning_categories.json 全体**が JSON ファイルとしてダウンロードされる（ファイル名: `kerning_categories.json`）。

### 4.2 エクスポート後の運用

- ダウンロードしたファイルで、プロジェクトの **`kerning_categories.json` を置き換える**と、次回以降の読み込み時にその内容が反映される。
- 複数フォントを編集したい場合は、フォントを変えるたびにエクスポートし、手動で `kerning_categories.json` にマージするか、エクスポートしたファイル同士をマージしてから 1 つの `kerning_categories.json` にする。

### 4.3 データ形式（エクスポート／kerning_categories.json）

`font_overrides` およびエクスポートされる形式は次のとおり。

```json
"font_overrides": {
  "フォント名": {
    "pair_adjustments": {
      "文字|文字": {
        "delta_norm": 補正値
      }
    }
  }
}
```

- **ペアのキー**: `"文字|文字"`（パイプ `|` 区切り）。例: `"ｔ|ｏ"`, `"Ｓ|Ａ"`。
- **値**: `delta_norm` のみ。フォントサイズに対する比率で、表示時の Δ(px) は `delta_norm × フォントサイズ` で計算される。

---

## 5. 初期表示時の補正値の適用

- パターン一覧タブで**フォントを選択**したとき、および**パターン一覧を表示・再描画**するとき、次の処理が行われる。
  1. `kerning_categories.json` の **`font_overrides[選択フォント名].pair_adjustments`** を参照する。
  2. 取得したオブジェクトをコピーし、**パターンタブ用の編集用オブジェクト**（メモリ上）に格納する。
  3. キャンバス描画時は、この編集用オブジェクトの `delta_norm` を**マニュアル調整と同様に**最終ギャップに加算する。
  4. マニュアル調整テーブルには、同じ編集用オブジェクトの内容が Δ(px) として表示される。

- フォント名の解決は、**そのまま** → **長音符の正規化**（`ー` → `-`）→ **フォントファミリー**（Mincho / Gothic 等）の順で行い、既存の `getPairAdjustmentsForFont` と同じロジックを使用している。

## 6. 基本設定タブとの違い（整理）

| 項目 | 基本設定タブ | パターン一覧タブ |
|------|----------------|------------------|
| 設定 | 1 文字列＋共通設定 | 設定のみ（文字列は pattern_list.json） |
| 設定の保存 | タブ切り替えで維持（同一セッション） | 同上。タブごとに独立。 |
| マニュアル調整の保存先 | LocalStorage（`manualKerningAdjustments_v1`） | メモリのみ。エクスポートで kerning_categories.json をダウンロード。 |
| マニュアル調整の初期値 | LocalStorage から | `kerning_categories.json` の `font_overrides` から |
| エクスポート | クリップボードに JSON コピー | kerning_categories.json 全体をファイルダウンロード |

---

## 7. 技術メモ（実装の要点）

- **設定の分離**: `patternTabPhaseMode`, `patternTabBeforeKerningGap`, `patternTabPhase0WidthAnchorEnabled` など、パターン一覧タブ専用の変数で保持。描画時のみ一時的にグローバルを差し替えて `computeKerningPositions` を呼び、終了後に復元。
- **補正の適用経路**: `computeKerningPositions(..., manualDeltaNormProvider, startX)`。パターンタブでは `manualDeltaNormProvider` に「編集用オブジェクトから pairKey で delta_norm を返す関数」を渡し、`startX = 8` で左余白を抑えている。
- **キャンバス**: 3 列グリッド（`repeat(3, 1fr)`）、各キャンバス 520×80px。
- **エクスポート**: `kerning_categories.json` を fetch し、`data.font_overrides[fontId] = { ...existing, pair_adjustments: { ...patternTabFontOverrides } }` でマージしてから `JSON.stringify(data, null, 2)` でダウンロード。

## 8. 変更履歴（実装で反映した内容）

- 新規タブ「パターン一覧」の追加（タブボタン・コンテンツ、表示時は基本設定のキャンバス／マニュアルエリアを非表示）。
- `pattern_list.json` の配置と、グループ＋items 構造、ローマ字（ヘボン式・訓令式）・小文字／大文字／先頭大文字の統合。
- フォント名に紐づく `font_overrides` の読み込みと、初期表示・描画への適用。
- 文字間マニュアル調整を「全ペア一覧」で表示し、編集結果をメモリで保持。
- 「kerning_categories.json をエクスポート」で全体ファイルをダウンロード（既存フォントは上書き、他はそのまま）。
- データ形式は `"フォント名": { "pair_adjustments": { "文字|文字": { "delta_norm": 補正値 } } }` で統一。
- キャンバス 3 列表示・幅 520px、左余白 8px によるはみ出し軽減。
